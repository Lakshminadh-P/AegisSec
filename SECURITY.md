# Security Policy

## Supported Versions

Currently, this is a portfolio project. Updates will be pushed to the `main` branch. Older versions are not actively maintained for security patches.

## Responsible Disclosure

If you discover a security vulnerability within AegisSec, please **do not** open a public issue. Instead, please report it privately:

1. Send an email to `placeholder@example.com` (replace with your actual contact email if deploying this repository).
2. Include steps to reproduce the vulnerability.
3. We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress.

## Educational Note

**AegisSec is an educational project.** It is designed to demonstrate DevSecOps principles, security scanning, and vulnerability management. It should not be used as a primary security solution in a production environment without further hardening and review.

## Intentionally Vulnerable Lab

This repository may contain an intentionally vulnerable lab application (`vulnerable-lab/`) for demonstration purposes. **DO NOT deploy the vulnerable lab to a publicly accessible server or production environment.** It is meant strictly for local testing to demonstrate the capabilities of the security scanners.
