# AegisSec — Resume Description

## 3-Line Project Summary

Designed and developed AegisSec, a web-based DevSecOps platform that integrates six security scanning tools (SAST, SCA, DAST, secret scanning, container scanning, IaC scanning) into a unified vulnerability management dashboard. Built with Python/FastAPI, the platform normalizes findings from different scanners, calculates risk scores, and provides actionable remediation guidance. Implemented CI/CD security gates using GitHub Actions, containerized deployment with Docker, and infrastructure security with Kubernetes and Terraform.

## Resume Bullets

- Built a full-stack DevSecOps security platform integrating Semgrep, Bandit, Trivy, Gitleaks, OWASP ZAP, and Checkov for comprehensive vulnerability detection across SAST, SCA, DAST, and IaC scanning
- Developed a vulnerability aggregation engine that normalizes findings from multiple security tools into a unified format with risk-based prioritization scoring
- Implemented CI/CD security pipeline using GitHub Actions with automated security gates that block deployment on critical findings
- Containerized the application using Docker with security best practices (non-root user, minimal images) and created Kubernetes deployment manifests with RBAC, security contexts, and resource limits

## Technology Stack
